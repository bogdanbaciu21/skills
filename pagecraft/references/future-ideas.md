# Future Ideas Not Yet In Flourishes.css

- **Viewport matrix previews:** one command that screenshots desktop, laptop, tablet, and mobile and emits a compact before/after contact sheet.
- **Semantic table linter:** verify every data table has caption/context, numeric class alignment, source notes, and no naked table overflow.
- **Number-format oracle:** repo-local JSON of accepted currency, percentage, multiple, bps, negative, and dash conventions, with a checker for inconsistent formats.
- **Density scales:** `.pc-density-comfortable`, `.pc-density-compact`, `.pc-density-boardroom` for tables/cards/dashboards.
- **Accessibility pass:** heading order, table header associations, focus order, color contrast, and reduced-motion validation.
- **Chart/exhibit grammar:** reusable caption, source, legend, units, and color-scale contracts for charts and SVG/canvas exhibits.
- **Empty/loading/error states:** standard visual language for dashboards and portal tools.
- **Citation/source components:** standardized source bars, footnote refs, methodology drawers, and confidence notes.
- **Design-token adapter:** script that maps a repo's tokens into Pagecraft variables without forcing a palette.
- **Print/export modes:** PDF-friendly page breaks, table shrinking, URL handling, and collapsed-details expansion as a first-class artifact check.
- **Content QA heuristics:** orphan heading detection, repeated heading text, "wall of cards" density warnings, long unscannable lists, and unsupported decorative overuse.
- **Interactive controls:** consistent segmented controls, filter bars, tabs, sortable table headers, and sticky action bars for operational tools.
