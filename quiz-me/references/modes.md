# Quiz Modes

## Finance

Use for FP&A, accounting, valuation, operating metrics, SaaS metrics, board
materials, and financial-modeling concepts.

Question mix:
- explain the metric
- interpret a small scenario
- spot an accounting or modeling trap
- choose what evidence would change the answer

## Code

Use for source files, codebase areas, APIs, shell commands, tests, and debugging
workflows.

Question mix:
- trace the flow
- predict the output
- spot the bug
- explain the test failure
- name the smallest safe change

## Interview

Use for job interviews, client diligence, investor meetings, and stakeholder
prep.

Question mix:
- concise behavioral answer
- case-style reasoning
- objection handling
- "what would you ask next?"
- crisp synthesis under time pressure
